# 健康生活小助手

定时提醒你**喝水**和**起身活动**的绿色小工具。双击即用，不用安装、不用装 Python、不写注册表。

## 一、安装（只有第一次需要）

1. 把 `健康生活小助手.exe` 放到一个固定文件夹（比如 `D:\软件\健康生活小助手\`），别留在下载目录。
2. 双击运行。
3. 若弹「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」（没买数字签名，不是病毒）。
4. 双击后**会自动打开设置页**（浏览器里一个漂亮的表单），同时屏幕右下角托盘区出现一个蓝色水滴图标，即装好了。

> 想放桌面：右键 exe →「发送到」→「桌面快捷方式」。
> 想开机自启：`Win+R` 输入 `shell:startup`，把快捷方式拖进去。

## 二、怎么用

**双击 exe → 自动弹出设置页**，五个数字直接改，点「保存设置」即时生效，不用重启。设置页可以关掉，提醒照常在后台跑。

- **喝水提醒**：默认每 60 分钟
- **起身提醒**：默认每 60 分钟

到点会在**屏幕右下角弹出气泡通知**（不抢焦点、不影响你正在打字或工作，几秒后自动消失）。

**右键托盘图标**，可以：

| 菜单项 | 作用 |
|--------|------|
| 打开设置 | 重新打开设置页 |
| 暂停提醒 / 继续计时 | 离开座位时暂停，回来接着算 |
| 喝了一杯 | 手动记一次喝水，倒计时重算 |
| 起身了 | 手动记一次起身，倒计时重算 |
| 今日清零 | 清空今日统计（不影响计时） |
| 结束（出报告） | 生成 HTML 报告并在浏览器打开，同时清零 |
| 退出 | 真正退出程序 |

## 三、设置页五个选项

| 设置项 | 说明 | 默认 |
|--------|------|------|
| 喝水提醒间隔 | 隔多久提醒你喝水 | 60 分钟 |
| 每次饮水量 | 你一杯大概喝多少 | 250 ml |
| 每日喝水目标 | 一天想喝多少 | 1900 ml |
| 久坐提醒间隔 | 坐多久提醒你起身 | 60 分钟 |
| 每日起身目标 | 一天想站起来几次 | 7 次 |

保存即生效，无需重启程序。

## 四、数据存在哪

统计和设置存在 `%APPDATA%\HealthyLifeAssistant\`（`Win+R` 输入 `%APPDATA%\HealthyLifeAssistant` 回车即可打开）。

- 设置会记住，下次打开不用重填
- 喝水/起身次数**每天重新算**，第二天自动清零
- 生成的报告也在该目录（`report_日期_时间.html`）

## 五、卸载 / 清空数据

1. 右键托盘图标 →「退出」
2. 删除 exe 所在的整个文件夹
3. 想连数据一起清：删除 `%APPDATA%\HealthyLifeAssistant` 文件夹

## 六、常见问题

- **双击没反应？** 可能被杀毒软件拦了，把 exe 加白名单再试。
- **设置页打不开？** 点托盘图标右键 →「打开设置」即可重新打开。
- **看不到托盘图标？** 点托盘左边 `^` 展开，图标可能被折叠了。
- **全屏看视频/游戏时提醒被挡？** 气泡通知在退出全屏后可见。
